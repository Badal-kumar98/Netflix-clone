## Overview

This project implements a full-featured streaming interface mimicking modern video-on-demand platforms. It demonstrates clean component modularity, dynamic media galleries, interactive accordion FAQs, and safe demo authentication flows.

## Tech Stack

- React 18
- Vite
- React Router (HashRouter for GitHub Pages compatibility)
- CSS3 (Responsive Grid and Flexbox layouts)

## Key Features

- Cinematic Hero Section: Responsive hero banner with call-to-action controls and dynamic typography.
- Media Showcase Grids: High-resolution cover cards with hover transitions and poster art.
- Interactive FAQ Accordion: Dynamic expand and collapse questions powered by modular data structures.
- Demo Sign-In Flow: Safe portfolio authentication simulation with feedback states.
- Cross-Device Responsiveness: Seamlessly tested across desktop, tablet, and mobile breakpoints.

## Local Development
